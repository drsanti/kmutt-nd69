# FreeRTOS exercises

This folder is reserved for a later Week 03 exercise. It does not yet contain a standalone FreeRTOS project or completed lab.

For the actual exercises, follow [freertos-pc-workshops](https://github.com/drsanti/freertos-pc-workshops) — a public student workshop pack for learning FreeRTOS on a PC: real kernel API, optional board-twin installers, and an optional web-client track. Clone it and work through its README:

```bash
git clone https://github.com/drsanti/freertos-pc-workshops.git
cd freertos-pc-workshops
```

First complete [ESP32-S3 Hello World](../esp32-s3/README.md), which demonstrates the `app_main()` entry point and a FreeRTOS task delay. For existing course material, read [Embedded C and FreeRTOS Engineering Fundamentals](../../../week02/lessons/EN/15-embedded-c-freertos-review.md).

Return to the [Week 03 lesson index](../README.md) for setup and tooling instructions.
