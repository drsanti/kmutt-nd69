## วัตถุประสงค์

1. ทบทวนและฝึกฝนทักษะการใช้งาน **Git**, **GitHub** และโปรแกรม **GitHub Desktop** สำหรับการจัดเก็บและติดตามประวัติเอกสาร/โค้ด
2. รวบรวม สังเคราะห์ และสรุปองค์ความรู้ทั้งหมดที่ได้ศึกษาตลอด **Week 01 ถึง Week 05**
3. ฝึกจัดทำเอกสารเชิงเทคนิคด้วยภาษา Markdown และนำเสนอผลงานผ่าน GitHub Repository ส่วนตัว

---

## ขั้นตอนการปฏิบัติงาน

1. **ศึกษาและฝึกฝนการใช้ Git & GitHub**
   - ศึกษาและทำความเข้าใจกระบวนการทำงานพื้นฐาน (Repository, Commit, Push, Branch ฯลฯ) ผ่านคู่มือ [GitHub Hands-On: A Practical Guide for Beginners](https://github.com/drsanti/github-hands-on)
   - ใช้ **GitHub Desktop** เพื่อความสะดวกในการจัดการ Repository บนเครื่องคอมพิวเตอร์ของคุณ

2. **จัดทำเอกสารสรุปเนื้อหา (Week 01 – Week 05)**
   - สรุปความรู้ ประเด็นสำคัญ และสิ่งที่ได้ลงมือปฏิบัติตลอด 5 สัปดาห์ที่ผ่านมา (เช่น การเข้าถึงฮาร์ดแวร์ผ่านเว็บเบราว์เซอร์, Browser Hardware APIs, Web Serial, Web Bluetooth, สถาปัตยกรรม Monitor & Control App, เครื่องมือ TypeScript/Vite และการทดลองต่างๆ)
   - เรียบเรียงเนื้อหาเป็นภาษาเขียนที่กระชับ ชัดเจน และจัดรูปแบบให้อ่านง่ายด้วย Markdown (`README.md`)

3. **นำเนื้อหาสรุปขึ้นสู่ GitHub**
   - สร้าง Repository ใหม่บนบัญชี GitHub ของตนเอง และกำหนดสิทธิ์เป็น **Public**
   - ทำการ Commit และ Push ไฟล์สรุปเนื้อหา (รวมถึงภาพประกอบหรือโค้ดตัวอย่าง หากมี) ขึ้นสู่ Repository

4. **ตรวจสอบและส่งงาน**
   - ตรวจสอบการแสดงผลของหน้า `README.md` บนเว็บไซต์ GitHub ให้เรียบร้อย
   - คัดลอก URL ของ Repository เพื่อนำมาส่งในแบบฟอร์ม
