# ND03 — Week 03: Hands-on with robotos

> Week02 was concepts — week03 is doing.
> Seven workshops, all on your laptop, no hardware required.

The ESP32-S3 board arrives next week. This week you run real robotos
nodes, topics, services, and parameters entirely on your machine —
and finish by building a mini digital twin.

## 📚 Contents

| Section | What's inside |
|---|---|
| [Workshops](workshops/) | 7 step-by-step guides: install → pub/sub → services → actions → params → record/replay → mini digital twin capstone |

## ⚙️ What you need

- robotos package for **your OS** — bundled in `workshops/code/`
  (Windows / macOS / Linux builds)
- Python ≥ 3.10 — the workshop language (SDK installs from a
  bundled wheel, no compilation)
- One laptop — no network, no board, no compiler
